Variables & Constants

Variables store values that can change, while constants store values that cannot be changed after initialization.

What is a Variable?

A variable is a named storage location used to store a value in a C++ program. The value stored inside a variable can be changed during program execution.

Think of a variable like a labeled box. The label is the variable name and the value inside the box is the data stored in that variable. 

int age = 18;
Part Meaning
int         Data type
age         Variable name
=         Assignment operator
18         Value
;         Statement terminator

Explaning cout :

cout is used in C++ to display output on the screen. It is part of the iostream
library and is commonly used with the insertion operator <<. You can use cout
to display text, numbers, variables, and the results of calculations. For example,
cout << "Hello World"; displays Hello World on the console, while cout << age; displays the value stored in the age variable. You can also combine text and variables
using multiple<< operators, such as cout << "My age is " << age;.

Why Do We Need Variables?

Variables allow us to store data and use that data multiple times in a program. They are especially useful when the value may change during program execution. 

int age = 18;
cout << age;

age = 19;
cout << age;

The value of age changes from 18 to 19.

Variable Syntax

The basic syntax for declaring and initializing a variable is:

dataType variableName = value;

Example:

int marks = 85;
double cgpa = 3.84;
char grade = 'A';

Declaration

Declaration means creating a variable by specifying its data type and name. 

int age;

Here, age is declared as an integer variable.

Initialization

Initialization means giving a variable its first value when it is created. 

int age = 18;

The variable age is created and initialized with the value 18.

Assignment

Assignment means giving a value to an existing variable or changing its current value. 

int age;
age = 18;
age = 19;

The current value of age is now 19.

Remember: Declaration creates the variable, initialization gives it its first value, and assignment changes the value later.

Common Data Types

A data type tells C++ what kind of data a variable is intended to store.

Data Type Used For Example
int Whole numbers int age = 18;
float Decimal numbers float price = 10.5f;
double Decimal numbers with higher precision double pi = 3.14159;
char Single character char grade = 'A';
bool True or false bool passed = true;
string Text string name = "Ali";

Variable Naming Rules

C++ variable names must follow certain rules.

1. Cannot start with a number

int age2 = 18;     // Correct
int 2age = 18;     // Incorrect

2. Spaces are not allowed

int studentAge = 18;     // Correct
int student age = 18;    // Incorrect

3. Use meaningful names

int studentAge = 18;
double accountBalance = 5000.50;
int totalMarks = 450;

Meaningful variable names make your code easier to read and understand.

4. C++ keywords cannot be used as variable names

int class = 10;     // Incorrect
int return = 20;    // Incorrect
int int = 30;       // Incorrect

5. C++ is case-sensitive

int age = 18;
int Age = 20;

age and Age are two different identifiers.

Changing Variable Values

A variable's value can be changed during program execution. 

int score = 50;

score = 75;
score = 100;

cout << score;

Output:

100

The current value is the most recently assigned value.

Constants

A constant is a value that cannot be modified after initialization. In C++, the const keyword is used to create a constant. 

const double PI = 3.14159;

After initialization, the value cannot be changed. 

const int DAYS_IN_WEEK = 7;
DAYS_IN_WEEK = 8; // Error

Why Use Constants?

Constants are useful for values that should remain fixed throughout the program. 

const double PI = 3.14159;
const int DAYS_IN_WEEK = 7;
const int MAX_MARKS = 100;

Using constants makes your code easier to understand and helps prevent accidental changes to fixed values.

Variable vs Constant

Variable Constant
Value can be changed Value cannot be changed
No const keyword required Uses the const keyword
int age = 18; const int DAYS = 7;
Reassignment is allowed Reassignment is not allowed

Complete Example

#include <iostream>
using namespace std;
int main() {

    string name = "Faris";
    int age = 18;
    int semester = 2;
    double cgpa = 3.84;
    char grade = 'A';
    bool passed = true;
    const int MAX_MARKS = 100;

    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
    cout << "Semester: " << semester << endl;
    cout << "CGPA: " << cgpa << endl;

    cout << "Maximum Marks: " << MAX_MARKS << endl;

    return 0;
}

Common Beginner Mistakes

Wrong Data Type

int price = 99.99;

If you need to store a decimal value, use an appropriate floating-point type such as double. 

double price = 99.99;

Using Double Quotes with char

char grade = "A"; // Incorrect
char grade = 'A'; // Correct

Using Single Quotes with string

string name = 'Faris'; // Incorrect
string name = "Faris"; // Correct

Changing a Constant

const int DAYS = 7;
DAYS = 8; // Error

Quick Revision

Variable: A named storage location whose value can change.

Data Type: Defines what kind of data a variable stores.

Declaration: Creating a variable without necessarily giving it a value.

Initialization: Giving a variable its first value.

Assignment: Giving or changing the value of an existing variable.

Constant: A value that cannot be modified after initialization.

const: Keyword used to create a non-modifiable object/variable.
