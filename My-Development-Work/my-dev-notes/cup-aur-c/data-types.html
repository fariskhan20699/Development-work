Cup aur C++

Data Types

A data type tells C++ what kind of data a variable can store and how that data should be handled by the program.

What is a Data Type?

A data type specifies the type of value that a variable can store. In C++, every variable has a data type. The data type helps the compiler understand whether a variable should contain a whole number, decimal number, character, true or false value, or another type of data.

For example, an age is normally stored as a whole number, while a CGPA can contain a decimal value. Therefore, we can use different data types for different kinds of information. 

int age = 18;
double cgpa = 3.84;

In the example above, int is used for the whole number and double is used for the decimal value.

Why Are Data Types Important?

Data types are important because they tell the compiler what kind of value a variable is expected to store. They also affect how much memory is required and which operations can be performed on the value.

Choosing the appropriate data type makes your programs easier to understand and helps you work with data correctly. 

int students = 50;
double price = 99.99;
char grade = 'A';
bool passed = true;

Common C++ Data Types

C++ provides several built-in data types for storing different kinds of values. The most common types beginners should learn first are:

1. int

The int data type is used to store whole numbers, also called integers. It can store positive numbers, negative numbers, and zero. 

int age = 18;
int marks = 85;
int temperature = -5;
int students = 40;

Examples of values that can be stored in an int variable include: 

100
0
-25
5000

An int should not be used when you need to preserve a fractional decimal value.

2. float

The float data type is used to store floating-point numbers, which are numbers that can contain decimal values. 

float temperature = 36.5f;
float price = 99.5f;
float height = 5.9f;

Notice the f at the end of the values. It tells C++ that the numeric literal should be treated as a float. 

float percentage = 85.5f;

3. double

The double data type is also used for decimal numbers. It generally provides more precision than float. 

double pi = 3.1415926535;
double cgpa = 3.84;
double price = 1499.99;

For many programs involving decimal values, double is a practical default when you need more precision than a float provides.

4. char

The char data type is used to store a single character. A character is written inside single quotation marks. 

char grade = 'A';
char symbol = '#';
char firstLetter = 'F';

A char stores one character, not a complete word or sentence. 

char grade = 'A';     // Correct
char grade = "A";     // Incorrect

Remember: 

'A'       → Character
"A"       → String

5. bool

The bool data type is used to store logical values. A Boolean variable can have one of two values: 

true
false

Example:

bool passed = true;
bool failed = false;
bool isLoggedIn = true;

Boolean values are commonly used when making decisions in a program. You will use them frequently with conditions such as if statements.

6. void

The void type represents the absence of a value. It is commonly used with functions that do not return a value. 

void showMessage() {
    cout << "Hello";
}

The function above performs an action but does not return a value. You will learn more about void when studying functions.

7. string

A string is used to store text, such as a name, sentence, or message. In C++, std::string is a standard library type rather than a fundamental built-in type like int or char. 

#include <string>

string name = "Faris";
string university = "Iqra University";

Strings use double quotation marks. 

string name = "Faris";

A string can contain multiple characters, while a char normally stores a single character. 

char letter = 'F';
string name = "Faris";

char vs string

Stores a single character             Stores text or multiple characters

float vs double

Both float and double can store decimal numbers. The main difference is their precision and typical storage size.

Feature       float       double
Decimal values       Yes          Yes
Precision       Lower         Higher
Typical size       4 bytes         8 bytes
Example      3.14f         3.1415926535
Beginner Tip: When you need a decimal value and do not have a specific reason to use float, double is often the simpler choice.

Data Type Size

Different data types generally require different amounts of memory. You can use the sizeof operator to find the size of a type or variable in bytes. 

cout << "Int = " << sizeof(int) << endl;
cout << "Double = " << sizeof(double) << endl;
cout << "Char = " << sizeof(char) << endl;
cout << "Bool = " << sizeof(bool) << endl;
cout << "Float = " << sizeof(float) << endl;

The exact size of some C++ types can depend on the compiler and platform, so you should not assume that every type always has the same size on every system.

For example, char is guaranteed to occupy one byte, while the sizes of types such as int, long, and double can vary by implementation.

Output

Int = 4
Double = 8
char= 1
Bool = 1
Float = 4

Signed and Unsigned Types

Integer types can be signed or unsigned. A signed integer can represent both positive and negative values, while an unsigned integer represents only non-negative values. 

int temperature = -10;
unsigned int students = 50;

An unsigned type can represent a larger range of non-negative values than the corresponding signed type of the same size.

Important: Do not use unsigned types simply because they sound like they provide "more memory." They use the same amount of storage as their corresponding type; the difference is how the range of values is represented.

Type Conversion

Type conversion happens when a value is converted from one data type to another. C++ supports both implicit and explicit conversions.

Implicit Conversion

An implicit conversion happens automatically when C++ converts a value to another compatible type. 

int number = 10;
double result = number;

Here, the integer value 10 is converted to a double.

Explicit Conversion

An explicit conversion is when the programmer intentionally tells C++ to convert a value to another type. 

double price = 99.99;
int wholePrice = static_cast<int>(price);

The decimal part is discarded, so wholePrice becomes 99.

Warning: Converting between types can sometimes cause loss of information. For example, converting 99.99 from double to int removes the fractional part.

How to Choose a Data Type

Choose a data type according to the kind of data your variable needs to store.

If you need to store...         Use
Whole numbers         int
Decimal numbers         double
A single character         char
True or false         bool
Text         string
No return value from a function         void

Complete Example

#include <iostream>
using namespace std;
int main() {

    int age = 18;
    float height = 5.9f;
    double cgpa = 3.84;
    char grade = 'A';
    bool passed = true;
    string name = "Faris";

    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
    cout << "Height: " << height << endl;
    cout << "CGPA: " << cgpa << endl;
    cout << "Grade: " << grade << endl;

    return 0;
}

Common Beginner Mistakes

1. Using int for a decimal value

int cgpa = 3.84;

If you need to preserve the decimal value, use double. 

double cgpa = 3.84;

2. Confusing char and string

char grade = "A";      // Incorrect
char grade = 'A';      // Correct

string name = 'Ali';   // Incorrect
string name = "Ali";   // Correct

3. Forgetting the f suffix for a float literal

float price = 10.5f;

Using f makes the literal a float. Without it, a decimal literal such as 10.5 has type double.

4. Assuming every data type has the same size

The size of several C++ types is implementation-dependent. Use sizeof() when you need to know the actual size on your system.

Quick Revision

Data Type: Defines what kind of data a variable can store.

int: Used for whole numbers.

float: Used for decimal numbers with lower precision than double.

double: Used for decimal numbers with higher precision than float.

char: Used for a single character.

bool: Used for true or false.

string: Used for text.

void: Represents the absence of a value, commonly in functions.

sizeof: Used to determine the size of a type or object in bytes.
